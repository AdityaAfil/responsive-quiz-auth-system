# Responsive Quiz & Authentication System

A responsive web application that provides user registration, login,
email verification, and an interactive quiz system.

## Features

- User registration
- User login
- Email OTP/verification
- Secure user authentication
- Responsive design
- Interactive quiz
- Score tracking
- User and quiz data storage

## Tech Stack

- React
- Vite
- JavaScript
- Supabase
- PostgreSQL
- Resend
- Vercel
